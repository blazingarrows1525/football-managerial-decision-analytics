# Data folders

| Folder | Contents | Edited? | In Git? |
|---|---|---|---|
| `raw/statsbomb/` | StatsBomb open-data JSON exactly as downloaded (`competitions.json`, `matches/{comp}/{season}.json`, `events/{match}.json`, `lineups/{match}.json`) | **Never** — cache only | No (re-downloadable) |
| `raw/synthetic/` | Files generated by `DEMO_SYNTHETIC` mode (fictional league) | No | No |
| `processed/` | Canonical / analytical tables written by the notebook export cell (CSV + Parquet) | Regenerated | No |
| `external/` | Your own authorised files: `user_statsbomb/` (USER_DATA mode, same layout as StatsBomb) and optional `managers.csv` | By you | No |

Provenance for every raw file (URL, UTC retrieval time, bytes, SHA-256, status) is written to
`outputs/exports/source_manifest.csv` by the notebook.

## Optional `managers.csv`
Only needed when the source has no manager metadata (StatsBomb `matches.json` usually does). Columns:
`match_id, team_id, manager_name[, manager_id, source]`. Enter only managers you can source; never from memory.

## USER_DATA mode
Place StatsBomb-format files under `data/external/user_statsbomb/` with the same sub-folders, set
`DATA_MODE = fcfg.USER_DATA` and the competition/season ids present in your `competitions.json`.
